# Contributing

To contribute you can edit the .json files adding more people's completions to it.

`leaderboard.json` stands for the extremes beaten by the Discord server's members.

Thumbnails can be found at `https://raw.githubusercontent.com/Gild56/gild56_website_lists/refs/heads/main/images/thumbnails/[level_name].png`

There are also thumbnails at `https://https://levelthumbs.prevter.me/thumbnail/[level_id]` but not every level has a thumbnail there

Cubes can be found at `https://raw.githubusercontent.com/Gild56/gild56_website_lists/refs/heads/main/images/cubes/[player_name].png`

Videos can be found at `https://youtube.com/watch?v=[video_id]`

Channels can be found at `https://youtube.com/@[channel tag]`

Files here can be found at `https://raw.githubusercontent.com/Gild56/gild56_website_lists/main/json/[file_name].json`
